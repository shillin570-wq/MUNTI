【一】计分与四字母（便于对照）
--------------------------------------------------------------------------------
• 每题 1–5 分；带「反向计分」的题目先折算为「越高越偏该维正向端」再入维。
• 四维均分 s/e/t/m 与阈值比较后得到四比特：
  s > 3 → C（协作侧），否则 A（捍卫侧）
  e > 3 → E（表达气场侧），否则 I（书证侧）
  t > 3 → S（文本颗粒侧），否则 N（愿景框架侧）
  m > 3 → P（台前游说侧），否则 H（幕后议价侧）
• 若四维组合命中「稀有剖面」规则，则结果为 HIDDEN_* 隐藏款，而非四字母码。
  具体阈值见 docs/RESULT_CONDITIONS.md。

【二】四维侧写（结果页「风格侧写」条 · dimensionLabels）
--------------------------------------------------------------------------------
策略（S）· 协商 vs 捍卫
  偏高：并案折中、互让一步、写进可表决案文
  偏低：划线守底、公开对峙、底线先于共识

表达（E）· 煽动性 vs 逻辑性
  偏高：讲台结构、临场叙事、全场能见度
  偏低：脚注数据、书面质询、以稿代讲

文本（T）· 细节 vs 大局
  偏高：条款颗粒、逻辑闭环、义务可追责
  偏低：章节骨架、愿景留白、细节后移

游说（M）· 台前 vs 幕后
  偏高：全会动议、有主持磋商、公开博弈
  偏低：茶歇耳语、走廊议价、双边小圈

【三】四字母各位 · 英文锚词 + 中文释义（RESULT_LETTER_EN）
--------------------------------------------------------------------------------
C · Collaboration
  策略上偏「织网并案」：愿为可表决文本付协调成本。
A · Assertive
  策略上偏「划线捍卫」：愿为底线承受公开对峙与延宕。
E · Expressive
  表达上偏「台前气场」：主发言、举牌与可见议程动作。
I · Informative
  表达上偏「书证脚注」：数据、工作文件与质询稿。
S · Specifics
  文本上偏「条款颗粒」：义务、编号、可追责与闭环。
N · Narrative
  文本上偏「愿景框架」：章节骨架、方向句与后移细节。
P · Public
  游说上偏「台前博弈」：全会、动议与公开拉票。
H · Hidden
  游说上偏「幕后议价」：走廊、茶歇与小范围双边。

———— CESP · 明星外交官（R）————
标语：聚光灯下，你把共识写成一场加冕礼。
定位：公开场建构者：用演讲与能见度把共识写成「众人愿意跟」的现场政治。
三关键词：情绪政治资本 / 公开盟约动员 / 演说—案文同频
趣味侧写：你的存在就是为了让别人自卑的。长得好看、说话好听，还能让大家心甘情愿给你打工。你不是来开会的，你是来开粉丝见面会的。
弧光：你走进会场的第一秒，空气里就响起某种“默认主角”的配乐。你不是在争话语权——你让话语权像追光灯一样自己靠过来。你擅长把复杂的利益博弈翻译成“我们一起赢”的叙事，让对手在掌声里放下戒备。
注意：当心把“受欢迎”误认为“已锁定票数”；记得给幕后留出兑现承诺的时间。
金句：“各位，让我们把掌声留给下一页序言——那里写着我们共同的未来。”

———— CESH · 亲和派领袖（R）————
标语：你把走廊走成了第二会场。
定位：走廊型织网者：把信任与私下承诺折成可表决的国家集团。
三关键词：一对一信任快充 / 筹码互换破局 / 私洽转公开背书
趣味侧写：会场里的“中央空调”兼“海王”。表面上和谁都称兄道弟，背地里早就把所有人的票数算得明明白白。
弧光：你真正的发言不在麦克风前，而在每一次擦肩而过的点头、每一次茶歇里的耳语。你相信信任是硬通货，而人情账户要在表决前夜兑现。你像织网一样把碎片化的立场缝成联盟，让“我们”这个词听起来像命运而不是话术。
注意：当心关系过载：每个人都觉得你“站在他那边”，最后可能谁都不满意。
金句：“我懂你担心什么——我们先把这句写进脚注，再把面子留给明天。”

———— CISP · 技术官僚（R）————
标语：你的武器不是音量，是无可辩驳的专业。
定位：条款型专家：以指标、脚注与证据链让立场「落地成文」。
三关键词：政策—条款翻译 / 证据压缩争议 / 质询结构化控场
趣味侧写：别人靠嘴炮，你靠PPT和数据。你一开口，会场瞬间变成学术研讨会，虽然大家听不懂，但大受震撼并默默签了字。
弧光：当别人还在用形容词堆砌立场，你已经把问题拆成指标、机制与时间表。你让“感觉不对”变成“这里不对”，让模糊的政治表态在脚注里落地。你不是冷——你是把冷静当作对议题的尊重。
注意：当心专业壁垒让盟友也听不懂；记得用一句人话总结你的核心主张。
金句：“请允许我用三组数据回答‘为什么必须现在做’。”

———— CISH · 政策专家（N）————
标语：你是集团背后那支从不抢镜的笔。
定位：幕后主笔：把集团的声量收成可签署、可防守的文件。
三关键词：口号沉淀为款 / 文本预埋棋眼 / 修订链护盟友
趣味侧写：集团里的“无情码字机”。当别人在前面风光无限时，你正在角落里疯狂敲键盘，修补他们吹牛留下的漏洞。

注意：当心过度修补导致文本臃肿；有时“少即是多”更能通过。

三关键词：可追随愿景 / 道义转议程动能 / 分裂中锚定共标
趣味侧写：会场里的“白莲花”（褒义）。你总是试图用爱与和平感化全场，虽然经常被现实毒打，但依然闪闪发光。
弧光：你擅长把“我们本来可以更好”说得像事实陈述。你愿意为更大的愿景承担短期代价，也愿意用制度设计去安放分歧。你不是天真——你是在用理想给现实搭脚手架。
注意：当心愿景太美而机制太薄；把理想拆成可验证的步骤。
金句：“如果我们连这句话都不敢写进序言，我们还来这里做什么？”

弧光：你擅长把“输赢”翻译成“可接受的体面”。你明白面子和里子可以分开打包：公开场域给台阶，私下场合换利益。你不是和稀泥——你是在降低战争成本。
注意：当心把自己燃尽：调停者的疲惫往往无人分摊。
金句：“我们先停在这里——给彼此一晚，把体面留给表决。”

注意：当心赢了解释权却输了联盟感；适时给出“我们一起推进”的台阶。

———— HIDDEN_LEADER · 领袖 / Leader（UR）————
标语：四维折算分同时站在高原上——这在人群里极少见。
定位：四轴同辉（极罕）：策略、表达、文本、游说折算分齐处高原（各维最低分仍 ≥ 约 4.35）。
三关键词：全频高投入 / 议程枢纽体质 / 场面—文件双强
趣味侧写：【UR】你几乎在每一条轴线上都把自己报到「强同意」区间：既愿协作推进，又愿公开表达与抠文本，还愿台前游说。现实里能长期维持这种全维高配的人不多，结果才会跳出十六格，单独成款。
弧光：你像会场的「全频共振体」：别人在补短板，你在同时开四条主战线。风险不是能力，而是燃尽与承诺过载——记得把「全能」拆成可轮换的角色。
注意：别让「我都可以」变成「谁都能透支你」；学会拒绝非核心战场。
金句：“既然四条线都要亮，那就把节奏写进时间表。”

———— HIDDEN_OBSERVER · 观察者 / Observer（UR）————
标语：四维同时贴近量表底部——一种罕见的自我收缩剖面。
定位：四轴同沉（极罕）：四条维度自陈同贴量表底部（各维最高分仍 ≤ 约 1.65）。
三关键词：全场低暴露 / 可逆空间大 / 情绪成本极低
趣味侧写：【UR】你在协作、表达、文本与游说上的自陈同时落在极低区。它未必等于「能力差」，更像一种极端保守的自我画像或当下状态；统计上极少与常见十六型重叠，故单列。
弧光：你像把音量集体静音：不是没听见，而是选择不把自己的能量交给任何一条赛道。若这是真实状态，需要分辨是保护机制还是低估自己。
注意：长期全低会被议程遗忘；选一条最小可行参与线慢慢试温。
金句：“我先听——但我会在我选的那一页上签字。”

———— HIDDEN_EXPERT · 专家 / Expert（SSR）————
标语：只有一维极高，其余三维同时偏低——「偏科型天才」样本。
定位：单峰塔型（罕见）：恰一维 ≥ 约 4.5，另三维均 ≤ 约 2.9。
三关键词：单点标签极强 / 对应战场利刃 / 资源集中爆破
趣味侧写：【SSR】你把几乎所有「同意」都灌进了一条轴：可能是策略、表达、文本或游说之一，其它维度则自我否定得很干净。十六型假设的是四轴组合平衡，你这种单极塔状在算法里被标为稀有异常值。
弧光：你像只开一束追光灯：全场只看见你的一种武器。用好它是杀手锏；用不好会被读成「只会一招」。
注意：盟友需要知道你的第二技能在哪里，否则不敢把后背交给你。
金句：“别的我不管——这一条线我负责到底。”

———— HIDDEN_VERSATILE · 多面手 / Versatile（SSR）————
标语：两维极高、两维极低——「对角式」稀有组合。
定位：双锋对角（罕见）：恰两维 ≥ 约 3.85 且恰两维 ≤ 约 2.15。
三关键词：反差难预测 / 互补角色切换 / 多轴筹码
趣味侧写：【SSR】你不是「差不多都行」，而是「一半燃烧、一半关机」。这种双核反差在代表里不常见：台上像外交官、台下像影子；或反过来。四字母格点难以概括，于是单列。
弧光：你像双城记：两个自我轮流值班。关键是让盟友知道哪一座城在值班表上。
注意：反差若无叙事支撑，会被读成不可信；给一句「我的分工逻辑」。
金句：“A 面负责赢掌声，B 面负责赢脚注。”

———— HIDDEN_GAME_CHANGER · 破局者 / Game Changer（SR）————
标语：四维极差极大——内在气候剧烈对流。
定位：锋面人格（稀有）：四维最高分与最低分之差 ≥ 约 2.25。
三关键词：乱局破局手 / 难被单维标签 / 复杂议题适配
趣味侧写：【SR】你允许自己在不同维度上极度不一致：可能极愿协作却极不愿公开游说，或极抠文本却极不care 表达气场。普通人会往「中庸」回归，你留在锋面上，故稀有。
弧光：你是会场的锋面系统：冷暖气团对撞才下雨。善用能造雨；失控则全场看不懂你。
注意：给盟友一个「天气预报」：何时会下雨、何时会放晴。
金句：“别用上一秒的我，预测下一秒的我。”

———— HIDDEN_BALANCER · 平衡者 / Balancer（SSR）————
标语：四维挤在窄带里，又恰好漂在中位——难标签化的稀有。
定位：镜湖中轨（稀有）：极差 ≤ 约 0.42 且四维均值落在约 2.72–3.28。
三关键词：低攻击性画像 / 易嵌入各集团 / 谈判弹性大
趣味侧写：【SSR】你不是「没性格」，而是「性格在统计上太平」：四轴彼此咬得很紧，又都贴着中线。十六型要的是可分的四比特，你这种镜湖样本会被算法温柔地请出格子。
弧光：你像湖面的倒影：清晰但难捉摸深度。真实会议里，你可能是多面手，也可能是高度情境依赖者。
注意：太均衡会被当成没有立场；关键时刻要交一次「锋利选择」。
金句：“我不站悬崖，我站解决方案。”

———— HIDDEN_ESTABLISHMENT · 建制派 / Establishment（R）————
标语：每一维都不低，但还不到「四岳同辉」的极端。
定位：高地板旅队（少见）：四维最低分仍 ≥ 约 3.85，未达「四岳同辉」更严阈值。
三关键词：稳定高在线 / 盟友安全感 / 持续存在感
趣味侧写：【R】你把自己报到「整体偏高同意」区：像一支全员在线、但还没开到极限档的旅队。常见十六型仍能描述你，但这种「高地板」在人群里比例有限，故单独标注为少见款。
弧光：你是会场的「高水位期」：不是洪水，但没人敢忽视你在场。
注意：别用「我都行」掩盖真实排序；学会说「我最优先的是…」。
金句：“我们先把水位线写进案文，再谈浪漫。”

———— HIDDEN_STRATEGIST · 战略家 / Strategist（R）————
标语：每一维都不高，但尚未沉入「夜海」极端。
定位：低云顶行营（少见）：四维最高分仍 ≤ 约 2.15，未落入「夜海同沉」更严区间。
三关键词：低姿态低树敌 / 长观察窗口 / 反转成本低
趣味侧写：【R】你在各维度上同步保持克制自陈：像低云覆盖，能见度不高但不至暴风。与「全维触底」不同，你仍保留中等偏下的活动空间；统计上也不常聚成典型十六型格点。
弧光：你像行营里的参谋：不轻易表态，却在算整条补给线。
注意：别被误读为「无所谓」；选一次明确举手打破低云。
金句：“我在等一句值得我抬头的话。”
